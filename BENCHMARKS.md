# FastFusion-IF benchmark plan

## 1. Main task definition

Task: partner-agnostic protein-protein interface prediction from one chain structure.

Label: residue is positive if any heavy atom from that residue is within 5 Å of any heavy atom from another chain in the biological assembly or complex.

Primary metrics:

- global PR-AUC,
- global ROC-AUC,
- median per-protein PR-AUC,
- median per-protein ROC-AUC,
- F1 and MCC at validation-selected threshold,
- end-to-end inference time including preprocessing.

PR-AUC and per-protein PR-AUC should be emphasized because interface residues are imbalanced and protein sizes vary.

## 2. Datasets

### DIPS-Plus

Best first training dataset. Use final/raw pair representations. Create your own MMseqs2/CD-HIT 30% sequence-identity manifest unless you intentionally use official FoldSeek splits from the supplementary record.

Recommended use:

- train/val/test for development,
- then retrain on train+val only after all hyperparameters are frozen if you need an external DB5/PINDER test.

### DB5 / DB5-Plus

Small curated external benchmark. Best use is external testing after training on DIPS-Plus. Do not tune hyperparameters on DB5 if you want to report it as an external benchmark.

### PINDER

Modern large-scale resource with gold-standard benchmark sets and an evaluation harness. Use after the model is stable. It is large, so it is not the best first training dataset on a normal workstation.

### BioLiP2 / ligand-binding datasets

Use only if you extend the objective from protein-protein interface prediction to general ligand/nucleic-acid/ion binding sites. Do not mix these into the PPI benchmark unless you clearly define a multitask problem.

## 3. Baselines to compare

### Must-have baselines

| Baseline | Reason |
|---|---|
| Atomic-only FastFusion-IF | Shows whether surface/fusion actually help. |
| Surface-only FastFusion-IF | Shows whether mesh-free surface representation is useful alone. |
| Late fusion without cross-attention | Tests whether bidirectional fusion is the innovation. |
| PeSTo | Strong structure/atom transformer baseline. |
| ScanNet | Strong interpretable geometric baseline. |
| MaSIF-site | Classic molecular-surface baseline. |
| dMaSIF | Efficient differentiable/on-the-fly surface baseline. |

### Optional literature baselines

| Baseline | Notes |
|---|---|
| PInet | Partner-specific geometric model; use when explicit partner structures are available. |
| GraphPPIS / GraphSite | Useful residue/graph baselines if code and dataset conversion are reproducible. |
| EquiPPIS / SE(3)-Transformer variants | Useful if you want a stronger equivariant comparison. |
| PointSite / DeepSurf | More relevant for small-molecule pockets than pure PPI, but useful for a binding-site discussion. |

## 4. Fair comparison rules

1. Use the same input structure type.
   - If FastFusion-IF sees one chain only, compare to partner-agnostic predictions.
   - If another method requires both partners, report it separately as partner-specific.

2. Use the same labels where possible.
   - For your own benchmark, recompute all labels using the same 5 Å heavy-atom rule.
   - If a baseline only outputs surface vertices, map vertex predictions to nearest residues before residue metrics.

3. Use the same splits.
   - Prefer official benchmark splits when they exist.
   - Otherwise use the manifest generated by `scripts/prepare_manifest.py` and publish it.

4. Do not tune on external benchmarks.
   - DB5 and PINDER test sets should be held out.

5. Report runtime honestly.
   - Include parsing, surface sampling, graph construction, and model forward pass.

## 6. Journal claim policy

A strong but safe claim after successful experiments would be:

> FastFusion-IF improves residue-level protein-protein interface prediction under leakage-safe homology-aware evaluation by combining atom-level chemical precision with mesh-free surface context through local cross-modal fusion.

Avoid claiming universal SOTA unless you reproduce baselines on matched splits and labels or evaluate with an accepted benchmark harness.
